# Описание дипломного проекта: «Веб-витрина косметических товаров»

## Введение
Целью дипломного проекта является разработка клиентской части одностраничного интернет-магазина (SPA), предоставляющего пользователю удобный интерфейс для просмотра каталога косметических товаров, добавления их в корзину и оформления заказа. Приложение реализует модальные окна для регистрации и корзины без перезагрузки страницы, что обеспечивает плавный пользовательский опыт. Проект выполняется в рамках учебной практики и служит демонстрацией навыков frontend-разработки: семантической вёрстки, работы с DOM, обработки событий, валидации форм и управления состоянием на чистом JavaScript.

## Актуальность темы
Современные интернет-магазины стремятся максимально упростить путь пользователя от выбора товара до оформления покупки. Одностраничные веб-приложения с модальными окнами позволяют выполнять ключевые действия (регистрацию, управление корзиной, оформление заказа) без перезагрузки страницы, что ускоряет взаимодействие, снижает количество отказов и делает процесс покупки более плавным. В учебных целях разработка такого приложения даёт возможность освоить ключевые навыки frontend-разработки, включая семантическую вёрстку, современные раскладки CSS, обработку событий, валидацию форм и управление состоянием интерфейса с использованием модульного JavaScript.

## Целевая аудитория
- **Покупатели косметической продукции** – конечные пользователи, которые просматривают каталог товаров, добавляют их в корзину, регистрируются и оформляют заказ.
- **Администратор магазина (потенциально)** – в будущем система может быть расширена панелью управления товарами и заказами (не входит в текущий MVP).
- **Обучающиеся и преподаватели** – проект служит демонстрацией практических навыков веб-разработки и может использоваться как учебный пример.

## Предполагаемые функциональные возможности
1. **Главная страница (одностраничное приложение)**
   - Каталог из 5 косметических товаров, представленных в виде карточек с изображением, названием, описанием, составом и ценой.
   - Фиксированные кнопки «Регистрация» (слева) и «Корзина» (справа) с динамически обновляемым счётчиком количества товаров в корзине.
2. **Модальное окно регистрации**
   - Поля ввода: имя, фамилия, дата рождения, логин, пароль, повтор пароля.
   - Клиентская валидация: все поля обязательны, минимальная длина логина (4 символа) и пароля (6 символов), проверка совпадения паролей.
   - После успешной регистрации кнопка «Регистрация» заменяется на имя пользователя, данные выводятся в консоль.
3. **Модальное окно корзины**
   - Отображение списка добавленных товаров с возможностью изменить количество (кнопки «+»/«-») или полностью удалить товар.
   - Динамический расчёт и отображение итоговой суммы заказа.
   - Кнопка «Оформить заказ» проверяет, зарегистрирован ли пользователь (если нет – предлагает пройти регистрацию), при успешном оформлении очищает корзину и выводит сообщение.
4. **Форма подписки в подвале сайта**
   - Поле для ввода email с проверкой корректности (допустимые домены: .com, .ru, .net и др.).
5. **Дополнительные взаимодействия**
   - Закрытие модальных окон по клику на крестик, по оверлею, а также по нажатию клавиши Escape.
   - Анимация появления модальных окон и эффекты наведения на интерактивные элементы.

## Используемые технологии (предварительно)
- **HTML5**: семантическая разметка (элементы `main`, `section`, `template`, `form`, `footer`), использование атрибутов `required`, `minlength` для нативной валидации.
- **CSS3**: Flexbox и Grid для построения адаптивной сетки каталога; фиксированное позиционирование кнопок и модальных окон; медиа-запросы для обеспечения корректного отображения на мобильных устройствах; переходы (`transition`) для плавных анимаций.
- **JavaScript (ES6+)**: 
  - Модульная архитектура с использованием `import/export`.
  - Классы `Modal` и `Form` для инкапсуляции логики модальных окон и работы с формами.
  - Управление состоянием корзины (добавление, изменение количества, удаление, подсчёт суммы).
  - Обработка событий (клики, отправка форм, нажатия клавиш).
  - Динамическое создание DOM-элементов на основе шаблона (`<template>`) и массива товаров.
- **Инструменты разработки**: VS Code, Git и GitHub для версионирования.

## Ожидаемый результат
- Полностью функционирующее клиентское веб-приложение без серверной части (SPA), позволяющее просматривать товары, управлять корзиной и проходить регистрацию.
- Три пользовательских экрана/состояния: основной каталог, модальное окно регистрации, модальное окно корзины.
- Семантически корректная, валидная и адаптивная вёрстка (корректное отображение на экранах шириной от 320px до 1920px).
- Чистый, модульный JavaScript-код, соответствующий современным стандартам, с разделением ответственности между классами и модулями.
- Реализованная клиентская валидация форм с понятными сообщениями для пользователя.
- Заложена основа для дальнейшего расширения: подключение backend, базы данных, системы авторизации, панели администратора.
